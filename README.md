# Spore Cell — Minecraft prototype

Мод стадии клетки для **Minecraft Java 1.21.1, Fabric Loader 0.16.10+, Java 21**.
Fabric API обязателен; сборка проверяется с **0.115.1+1.21.1**.
Обычный мир и инвентарь сохраняются: режим работает в собственном измерении `sporecell:pond`.

## Запуск

1. Установите профиль Minecraft **1.21.1 с Fabric**, отдельно от установленного 1.21.7.
2. Соберите `./gradlew build` (Windows: `.\gradlew.bat build`).
3. Положите `build/libs/spore-cell-0.1.0.jar` и Fabric API для 1.21.1 в `mods` **этого профиля**.
   Не используйте `-sources.jar`. На выделенном сервере мод и Fabric API нужны и клиенту, и серверу.
4. Откройте мир и выполните `/cell enter` — команда доступна без прав оператора.
5. **WASD**: плавание относительно экрана. **G** или `/cell editor`: редактор.
6. `/cell leave`: вернуться в исходное измерение, позицию и игровой режим.

Для запуска из исходников без установки игрового профиля: `.\gradlew.bat runClient`.
Первое скачивание зависимостей и ресурсов Minecraft требует сети.
В этой рабочей папке можно использовать `--gradle-user-home .gradle-home`, чтобы хранить кэш локально.

## Редактор и игровой цикл

Слева выбирается часть и показана её цена. На сетке 9×9: ЛКМ — установить/заменить,
ПКМ — удалить, R — повернуть выбранную часть на 90°. Стрелка показывает направление действия.
Для перемещения части удалите её и поставьте в другую ячейку; вращение существующей части — повторная установка.
Ядро закреплено в центре. До 49 деталей, все детали должны соединяться сторонами с ядром.
Можно временно строить несвязную конфигурацию, но применить её нельзя.
Предпросмотр и параметры обновляются сразу; Apply применяет изменения в мире.

Начальный запас — 12 ДНК. Растительная пища зелёная (+2 ДНК), животная — розовая (+3).
Подведите соответствующий рот к пище с нужной стороны. Имеющаяся конструкция полностью учитывается
при обмене частей: оплачивается разность цен, удаление возвращает стоимость.
Отмена редактора не меняет клетку и баланс.

Жгутик даёт тягу, реснички — поворот, глаз — видимость пищи и организмов, броня — здоровье.
Рот хищника и шип атакуют в пределах передней дуги каждой детали; здоровье восстанавливается от еды.
Смерть возвращает клетку в центр с короткой неуязвимостью; ДНК и конструкция сохраняются.
NPC блуждают, ищут еду, преследуют более слабые клетки и убегают от более сильных хищников.
Во время редактирования клетка неподвижна и защищена от атак.

## Данные и настройки

* `config/sporecell-parts.properties` создаётся при запуске из встроенного `parts.properties`.
  Формат: `цена, здоровье, тяга, поворот, обзор, урон, RGB`. После изменения нужен перезапуск.
  Сервер передаёт свои значения клиенту; локальная конфигурация клиента не определяет баланс сервера.
* Конструкция: список `{x,z,part,direction}`, где direction — 0..3 (север, восток, юг, запад).
* Прогресс: `data/sporecell.dat` в сохранении обычного мира, профили по UUID игрока,
  версия схемы 1. Сохраняются конструкция, ДНК, здоровье, статистика, статус режима и точка возврата.
* При повторном входе/перезапуске активная клетка создаётся в центре водоёма из сохранённой конструкции.
  Местоположение внутри водоёма не сохраняется.

## Проверки

```
.\gradlew.bat test build
.\gradlew.bat runGametest
.\gradlew.bat runEditorTest
.\gradlew.bat runWorldTest
```

JUnit проверяет связность, ядро, пересечения, бюджет, характеристики, направление и JSON.
GameTest выполняет игровой цикл на настоящем сервере Minecraft; его исходники и отдельный
тестовый пресет мира не включаются в распространяемый JAR.
`runEditorTest` открывает настоящий экран редактора в игровом клиенте, проверяет размещение,
поворот и удаление, сохраняет `build/clienttest/screenshots/cell-editor-<timestamp>.png` и закрывает клиент.
`runWorldTest` создаёт отдельное одиночное сохранение в `build/worldtest`, проверяет управление,
видимость клетки, сетевое применение редактора и возврат из режима, сохраняет снимки мира.
В 1.21.1 GameTest игнорирует реестр дополнительных измерений и создаёт мир из пресета `flat`,
поэтому только тестовый мод дополняет этот пресет водоёмом.

## Границы прототипа

Реализуется только стадия клетки. Водоём конечный (97×97), на общей плоскости, без сложной экосистемы.
Редактор использует сеточный объёмный эскиз; свободного 3D-редактирования нет.
Набор типов деталей фиксирован, их численные характеристики и цвета настраиваются в конфигурации.
Выход из режима восстанавливает исходное состояние персонажа; используется стандартная spectator-камера
как технический носитель управления собственной сущностью.

Собственные модели состоят из кубических деталей; тело не размещает блоки в мире.
Код и ресурсы Spore не используются. Статус исследования: [docs/research/spore.md](docs/research/spore.md).
Архитектура и решения: [docs/architecture.md](docs/architecture.md).
Результаты проверок и их границы: [docs/testing.md](docs/testing.md).
