## Что реально выполнено

1. REA MCP открыл файл и связал Ghidra с его SHA-256. Первый запрос поиска строк запустил
   настоящий headless-процесс, импорт и автоанализ. Ожидание завершилось `provider_timeout` через 330 с.
2. Повторная попытка REA CLI с увеличенным сроком встретила `EACCES` при создании защищённого
   снимка бинарного файла. Настройки доступа и sandbox не менялись.
3. Ghidra запущена напрямую через официальный Java entry point. Все настройки, кэш, проект
   и логи направлены в рабочую папку. Для автоанализа установлен лимит 1200 с.
4. Импорт завершился успешно. Ghidra выделила **57 035 функций**. Автоанализ достиг лимита:
   это **частично проанализированная программа**, а не доказательство полного восстановления игры.
5. Собственный read-only post-script выполнил поиск определённых Ghidra строк, получил xref
   и **успешно декомпилировал три найденные функции**. Скрипт завершился маркером `DONE`.
   Финальный лог содержит `Post-analysis succeeded`, `Save succeeded`, `Import succeeded`.

Это результаты прямой Ghidra CLI, не REA Evidence-записи. Для успешной части исследования
REA Evidence ID не выдавался; приписывать ему результаты прямого запуска нельзя.

## Подтверждённые наблюдения

Адреса ниже относятся только к указанному SHA-256. Имена `FUN_*` сгенерированы Ghidra.

| Наблюдение | Опорные данные | Что это подтверждает |
|---|---|---|
| Разные параметры поворота ресничек и жгутиков | `ciliaTurnSpeed` по `0x014836a0`; `flagellaTurnSpeedMin` по `0x014836c8`, `flagellaTurnSpeedMax` по `0x014836b0`; xref в `0x0137bcc0` | В бинарном файле есть отдельные именованные параметры; декомпиляция показывает их регистрацию |
| Параметры разгона жгутиков | `flagellaRampMinFactor`, `flagellaRampTime`, `flagellaRampResetAngle`, `flagellaTurnSpeedRampStart/End`; xref в `0x0137bcc0` | Разгон/изменение поворота представлены несколькими настройками; точная формула из этого не следует |
| Отдельные множители поворота NPC | `npcTurnSpeedMultiplier_Cilia`, `npcTurnSpeedMultiplier_Flagella` по `0x01483870`/`0x01483890`; декомпиляция `0x0137bcc0` также показывает вариант Jet | Каталог настроек отличает NPC и способы движения; это не восстановление поведения NPC |
| Именованные эффекты двигательных органов | `cell_propulsionCilia` по `0x0148584c`, `cell_propulsionFlagella` по `0x01485834`; xref в `0x00e73f60`, `0x00e67670` | Есть разные ссылки на эффекты. Их присутствие не доказывает физическую модель органов |

Функция `0x0137bcc0` повторяет структуру: сохранить имя, получить соответствующий идентификатор,
сохранить описание поля и дополнительные метаданные. На этом основании её роль как регистрации
параметров — обоснованный вывод по псевдокоду, а не восстановленное исходное имя.
Числа в описаниях полей могут быть смещениями; **они не приняты за значения баланса**.

`0x00e73f60` использует имена propulsion-эффектов в вызовах общего вспомогательного обработчика;
`0x00e67670` регистрирует группу именованных эффектов. Их точное значение и жизненный цикл
без исследования обработчиков остаются неизвестными.

## Границы и неизвестное

| Подсистема | Статус |
|---|---|
| Движение | Частично: обнаружены настройки и их регистрация, формулы/единицы/значения не восстановлены |
| NPC | Частично: обнаружены множители поворота; состояния и принятие решений не исследованы |
| Пища | Не установлено по бинарному коду |
| Здоровье, урон, смерть | Не установлено по бинарному коду |
| ДНК и прогрессия | Не установлено по бинарному коду |
| Редактор, связность, ограничения размещения | Не исследовано |
| Способности частей | Обнаружены имена двигательных параметров/эффектов; полные характеристики не восстановлены |

Поиск ограничен шаблоном `cell.*(speed|health|food|turn|dna)|flagell|cilia` среди **определённых строк**
частичного анализа Ghidra. Отсутствие результатов по теме не означает отсутствие подсистемы.
Есть предупреждения декомпилятора о неразрешимых адресах в других функциях; PDB отсутствует,
косвенные вызовы и точность границ функций могут быть неполными. Ни один вывод здесь
не утверждает наблюдение поведения работающей Spore.

## Собственная реализация мода

Сглаживание скорости, ограничение угловой скорости, формула массы, дуга атак, поведение NPC,
цены частей, ДНК, здоровье и правила сетки — **собственные проектные решения прототипа**.
Они не выдаются за алгоритмы оригинальной игры. Разделение тяги и манёвренности согласуется
с найденным разделением параметров, но численные значения мода выбраны самостоятельно.

## Повторение и локальные материалы

Запуск: `powershell -File tools/Run-SporeProbe.ps1` с параметрами путей при необходимости.
Скрипт `tools/ghidra/CellStageProbe.java` ограничивает декомпиляцию четырьмя функциями, найденными
через опорные строки. В этом запуске уникальных кандидатов было три.

* `build/research-ghidra/analysis.log` — журнал импорта и анализаторов.
* `build/research-ghidra/script.log` — журнал скрипта.
* `docs/research/evidence/ghidra-cell-probe.txt` — локальные строки, xref и псевдокод трёх функций.

Большие временные материалы и псевдокод исключены из Git через `.gitignore`. В репозиторий
входят этот отчёт и собственные скрипты исследования; бинарные файлы и ресурсы Spore не входят.
